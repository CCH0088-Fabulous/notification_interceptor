# APK 内测使用指南

适用于研究者提供的普通离线内测包，无需注册、登录或填写服务器地址。

1. **安装与授权**：在 Android 8.0 及以上手机打开 `app-release.apk`，按系统提示安装「通知拦截器」。首次打开后点「去授权」，在系统设置中开启本应用的通知使用权，返回后确认显示「监听中」。遇到安装或授权限制，请联系研究者。

2. **设置过滤**：进入「规则 → 新建规则」，按测试要求选择应用、填写关键词、选择「移除」，预览后保存，确认规则和全局开关均已开启。让目标应用发送一条包含该词的通知，在「历史」查看处理结果。通知可能短暂闪现或先响铃；部分通知会被系统拒绝取消。

3. **体验高级功能**：进入「设置 → 高级功能」，可保存关键词与场景预设；保存后确认应用才会生效。当前内测开放体验，无需付费。详细操作见[预设使用说明](presets.md)。

4. **自愿开启内测记录**：进入「设置 → 内测数据 → 开始参与内测」，阅读说明后点「同意并开始」，之后照常使用。「包含脱敏规则结构」默认关闭，可自行选择；拒绝参与不影响通知过滤。

5. **结束并交回数据**：在「内测数据」点「结束记录，保留数据」并确认，再点「分享内测数据」。选择支持附件的微信、QQ 或邮箱，选中研究者并发送生成的 ZIP，无需解压或改名。找不到分享目标时，点「保存到手机」，再将保存的 ZIP 作为附件发送。

分享面板打开不代表对方已收到。请等研究者确认后，再按需点「删除本机研究数据」；交回前请勿卸载应用或清除应用数据。

通知统计不含常驻通知和系统分组汇总；常驻记录仍可查看，并照常按规则处理。

研究文件包含本应用使用时长、通知处理数量和操作记录，不含通知正文、发送人、联系人或具体过滤词。事件明细最多保留 **14 天**，小时汇总最多 **30 天**，达到容量上限可能提前裁剪；结束记录后仍适用，请及时分享。应用不会自动上传。
