# 离线内测数据：本地记录，结束后分享

入口：设置 → 内测数据。页面沿用白底黑字和离线思源宋体。普通内测包无需账号、邀请码、公网地址或电脑联网，也不会自动登记、自动上传。

## 给测试者的操作

1. 首次启动应用会展示采集说明，“记录内测数据”和“包含脱敏规则结构”默认勾选，点“同意并开始”后一起开启。可以取消任一选项或选择“暂不参与”；拒绝不影响通知过滤，也不会每次启动反复询问。
2. 平时照常使用。可在本页单独关闭“包含脱敏规则结构”。之前已关闭、已结束或已配置的内测状态在升级后保留，不会自动重开。不参与的用户可点“开始参与内测”重新选择；已结束的轮次需先分享并删除旧数据，才能开始新一轮。
3. 结束时点“分享内测数据”，应用自动生成一个 ZIP 并打开安卓系统分享面板。选择已安装且支持附件的聊天工具或邮箱，再选收件人发送；无需寻找目录、打开文件或改名。具体微信/QQ版本需在真实手机验收。
4. 分享不方便时，点“保存到手机”，通过系统文件选择器保存同样的 ZIP。取消或失败不会清除记录。
5. “结束记录，保留数据”停止新增采集，原编号与数据继续保留；重启后仍能分享。确认研究者收到后，再单独“删除本机研究数据”。删除后重新参与会生成新编号。

分享按钮只表示文件已生成、分享界面已打开，应用无法确认收件人是否收到，因此不会提示“发送成功”或自动清空。用户保存、发送的副本需自行管理。记录结束后，原数据仍受 14/30 天与容量裁剪限制。

## 采集范围与解释

- 本软件前台会话、时长；过滤开启与监听连接的已观测区间。单调时钟检查间隔超过 90 秒或明显校时记为观测缺口，不推断持续保护，不持有唤醒锁。
- 按小时汇总的通知处理、保留、仅记录、命中移除、最终成功/失败/拒绝/未确认结果。通知更新仍为处理事件，重连补读用 `existing_` 单列。常驻通知（系统 `isOngoing` 标记）与系统汇总均排除在处理量、动作和取消结果之外；排除次数只以 `ongoing_excluded` / `summaries_excluded` 诊断计数保留。
- 页面/场景/预设操作、规则保存变更、清空/导出历史等固定类别计数。事件明细包含时间点和固定类别/计数，不包含自由文本。
- 可选脱敏结构仅含来源、动作、开关、匹配方式、词/应用数量区间及条件有无；不含规则 ID、名称、具体词语、正则、包名或具体日程。结束后仍可关闭结构分享，清除本机快照；旧文件需另行处理。

不采集通知正文、发送人、联系人、整个手机或其他应用使用时长。导出不读取 `history.jsonl`。编号可关联一轮多日记录，不代表完全匿名或独立人数；这些统计不能直接证明节省时间、减少查看手机或降低漏看。

生成器、Probe、Shell 测试来源强制归演示，模拟器默认演示，真实使用与演示分开分析。

常驻排除口径适用于更新后的新增研究记录。旧版小时汇总没有通知标记，无法追溯扣除常驻数量，不会改写或清空；比较不同轮次时需注明口径。

## 保存期限与容量

| 数据 | 手机保留范围 |
|---|---|
| 事件明细 | 14 天，最多 50000 条 |
| 小时汇总 | 30 天，最多 4096 组 |
| 研究 SQLite | 64 MiB，按实际页大小设置页数上限 |
| 临时分享文件 | 最多保留最近 3 个 ZIP，失败的中间文件下次生成时清理 |

研究数据库为 `noBackupFilesDir/research.sqlite`，不参与 Android 自动备份，与最多 1000 条通知历史分离。扩大期限不能恢复已经被旧版裁剪的数据。裁剪及本进程采集失败会在页面与导出文件说明，容量限制下不承诺无丢失。

每次导出包含全部现存小时和事件，不受在线的 96 组/512 KiB 批次限制，也包含已获在线确认的快照；不改变在线 ACK、不清空本机库。ZIP 内固定为 `research.json`，ZIP 上限 24 MiB，原始 JSON 上限 64 MiB。导出在原生后台线程流式写入，避免把完整事件列表传到 Flutter 或系统消息通道。事件 ID 加盐散列，避免直接导出本机通知历史条目 ID。

## 电脑回收

无需开启任何公网入口。研究者下载收到的 ZIP，在[电脑本地管理端](local-receiver.md)“导入内测文件”选择文件即可。支持一次最多 10 个文件，最多接纳 10 个离线编号。编号可备注“试用者 A”，不验证真实人员或物理手机数量。

同一导出编号幂等确认；较新小时修订覆盖旧值，事件按编号去重，冲突整份回滚。图表只汇总小时，明细不再次叠加；可单独导出事件 CSV。手机保留期不自动删除电脑已导入数据、聊天副本或导出文件，需另行管理。

## 构建与旧版升级

普通离线包直接 `flutter build apk --release`，不必运行公网配置工具。默认 `RESEARCH_ONLINE_ENABLED=false`，不嵌入在线接收地址或登记凭证；遗留发送任务会取消，旧上传凭证清除。

研究说明已升级到版本 2，明确 14 天事件明细及手动文件回收。旧同意版本暂停新增采集，已有明细继续按原来的 7 天裁剪，可先分享，再清除后阅读新说明开始新一轮，不会静默扩大旧研究范围。

在线 v1 上传与登记接口为兼容/开发用途保留；只有通过配置工具显式 `--enable-online` 才生成在线兼容构建。当前普通内测页面采用离线回收，不要求用户操作网络字段。
