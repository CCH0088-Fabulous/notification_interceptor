# 电脑本地研究接收端

回收手机端自愿参与研究后的统计，保存在这台电脑的 SQLite 中；无需云数据库。当前推荐[离线分享模式](research.md)，电脑只需在整理数据时启动，不需要公网 HTTPS 或隧道。

## 离线文件回收（当前主流程）

1. 测试者在手机“设置 → 内测数据”点击“分享内测数据”，通过系统分享发送一个 ZIP。
2. 在电脑下载文件，启动下面的本地程序，登录管理页，进入“导入内测文件”（`http://127.0.0.1:8766/imports`）。
3. 选择手机生成的 ZIP，点击“导入并合并统计”。每次最多 10 个文件，单 ZIP 最大 24 MiB，整个请求最大 32 MiB；只在内存中读取固定 `research.json`，解压内容不写磁盘，上限 64 MiB。
4. 查看编号备注、周期、小时组/明细条数、裁剪与采集失败说明，进入原有统计页；也可导出该编号全部已回收事件 CSV。

同一编号重复导入不增加人数或重复相加；小时较高修订替换、事件按 ID 去重、同修订/ID 内容冲突整份回滚。最多接纳 10 个离线编号，删除可释放名额并拒收原编号。电脑的记录及外部文件不按手机 14/30 天保留期自动清理。可在电脑改备注，不能据文件验证真实人/设备或保证文件未被改动。

SQLite 自动升级到 v3：增加离线编号、导入记录和事件明细，保留旧小时统计与在线令牌。

## 启动与打开

在仓库根目录运行（Windows / Python 3.10+）：

```powershell
.\tool\start_research_receiver.ps1 -Background
```

首次运行会在 `.local/receiver-env` 创建独立 Python 环境并安装 Flask、Waitress，不修改全局 Python。此电脑优先使用现有 `D:\Anaconda\python.exe`，其他电脑使用 PATH 中的 Python。依赖安装失败后可重试：

```powershell
.\.local\receiver-env\Scripts\python.exe -m pip install -r tool/research_receiver/requirements.txt
```

- 管理页：<http://127.0.0.1:8766>。管理密钥保存在 `.local/research-receiver/admin-key.txt`，复制文件内容登录。
- 手机上传接口：`http://127.0.0.1:8765/api/research/upload`。
- 两个监听器都只绑定 `127.0.0.1`，上传端口没有管理页。

```powershell
.\tool\start_research_receiver.ps1 -Action status
.\tool\start_research_receiver.ps1 -Action stop
# 如需更换端口，先停止，再启动：
.\tool\start_research_receiver.ps1 -Background -UploadPort 8765 -AdminPort 8766
```

省略 `-Background` 可在当前终端运行，用 Ctrl+C 停止。脚本重复启动会提示已有服务，数据目录加锁防止多个进程同时管理。停止命令针对本次运行实例，不按未经验证的旧 PID 杀进程。

## 在线兼容模式（可选开发用途）

当前普通内测包默认离线，不需要本节配置或网络凭证。显式在线开发构建需给配置工具加 `--enable-online`；以下旧网络流程仅为兼容说明，当前内测页面不展示手工网络字段。

### 免登录内测（最多 10 个安装）

在管理页“内测设备”（`/pilot`）开放新登记，然后配置内测 APK：

```powershell
.\.local\receiver-env\Scripts\python.exe tool/configure_research_pilot.py --endpoint http://10.0.2.2:8765/api/research/upload
flutter build apk --debug --target-platform android-x64
```

上面地址仅供模拟器调试。面向异地真机分发前，把 `--endpoint` 改成已部署的 HTTPS 上传地址，再构建对应手机架构的 APK。构建配置保存在忽略的 `.local/research-pilot.properties`，包含接收地址与仅用于登记的凭证；不包含管理员密钥或任何设备的上传令牌。更换接收服务器时需使用该服务器的登记凭证重新构建。

已参与设备保留此前确认的接收方；更新安装包不会静默迁移统计和凭证。若更换接收方，需退出研究并重新加入，阅读新目的地并申请新安装名额。

同一个内测 APK 可分发给所有测试者。用户在手机明确同意研究后自动登记，无账号、验证码、邀请码或手填令牌。每个安装生成并加密保存独立随机上传凭证，服务器只保存哈希并绑定该编号。首次登记会使用当前可用网络，只发送随机编号与同意版本；统计上传仍遵守 Wi-Fi/后台开关。失败后可点“重新连接”，沿用之前的编号和凭证；关机或进程重启不会重新占名额。登记成功本身不允许后台上传，用户仍需另行确认。

接收端默认关闭新登记，写事务保证最多 10 个安装。关闭登记不影响已有安装上传和登记确认重试；撤销上传权限不释放名额，也不能通过重复登记恢复。管理页可修改“试用者 A”等本机备注；明确删除安装后释放名额并拒收原编号，可清理重装/退出产生的旧安装。新编号不是新的独立用户证明。

SQLite v1 启动时自动增加 v2 登记表，保留已有数据和手工令牌。旧版手工上传令牌仍兼容，10 名额限制针对新增的免登录登记流程。原 APK 的管理员登录仍只属于电脑管理页。

### 手工配置（兼容旧版/调试）

1. 登录管理页，进入“上传令牌”，为测试设备创建令牌。原文仅创建时显示一次，电脑数据库只保存哈希。每台安装实例使用自己的令牌，首次有效上传后绑定研究编号。
2. 在调试 APK 的“设置 → 使用研究与发送”中，阅读说明并开启参与。接收地址填 `http://10.0.2.2:8765/api/research/upload`，上传令牌填刚创建的手机令牌；管理密钥不填进手机。
3. 研究分组选“演示／测试”。模拟器网络如果被系统标为计费网络，联调时需明确关闭“仅不计费网络发送”，然后保存。
4. 生成一些测试通知、切换页面，点击“立即发送”并确认目的地。收到匹配批次确认后，手机更新已确认状态；管理页选择“演示 / 测试”可见数据。
5. 使用“导出 CSV”获取筛选范围内的小时记录。退出软件后重启接收服务，数据仍保留。

真机里的 `127.0.0.1` 是手机自身；`10.0.2.2` 只适用于 Android 官方模拟器。通过 USB 测调试 APK 时，可针对设备执行 `adb reverse tcp:8765 tcp:8765`，手机填 `http://127.0.0.1:8765/api/research/upload`，结束后执行 `adb reverse --remove tcp:8765`。正式 APK 仍仅允许 HTTPS。

异地手机不能仅凭电脑本地地址访问。后续需设置 HTTPS 入口，将上传请求转发至 8765，保持 8766 管理页仅本机可用；本轮没有安装隧道、开放路由器、防火墙或开机任务。电脑关机、休眠或服务停止时无法接收，手机保留未确认批次并按现有策略重试，仍受设备侧 30 天/容量裁剪限制。手机调度仍约每 4 小时尝试，尚未实现白天窗口。

## 数据与管理

全部运行文件位于 `.local/research-receiver/`：`receiver.sqlite3`、WAL/SHM、管理密钥、会话签名密钥、运行状态及启动日志。`.local/` 已忽略，不提交 Git，也不会随 `flutter clean` 删除。当前接收端不自动按日期清理数据，磁盘容量决定上限；设备侧 30 天保留不等于电脑侧保留期限。试用开始前应另行约定电脑侧保留期。

免登录内测另有 `enrollment-key.txt`，仅授权新安装登记。请勿与管理员密钥或上传令牌混用。登记凭证会随内测包分发，登记名额不能用作真实设备或人员身份验证；人员到齐后关闭新登记即可。

管理页支持日期与真实试用/演示分组筛选、安装实例详情、脱敏结构、令牌创建/撤销、删除实例和 CSV 导出。日期边界统一 UTC+08:00，CSV 同时保留 UTC 时间和设备偏移。未收到数据的小时不补零；缺失指标只在已有小时快照中按零读取。

每小时数据是累计快照：高 revision 覆盖低 revision；重复 batchId 返回相同确认；同一批次/修订内容冲突报 409，整批回滚。较新同意配置关闭规则结构时，电脑删除该实例现有结构；旧批次不能恢复分享范围。若手机断网尚未发送关闭状态，电脑需手动删除。

撤销令牌停止后续上传，不删除已收数据。在详情页输入完整研究编号删除，将清除其批次、小时、规则结构，撤销相关令牌，并保留编号哈希拒收标记，阻止旧队列重建数据。该操作也适用于用户退出研究后的删除请求。CSV、其他副本和备份需要另行删除；电脑文件依赖操作系统账户权限，不提供磁盘加密或多管理员权限系统。

备份前停止服务，将整个数据目录复制到受控位置，包含凭据的备份不应共享。当前服务不记录请求体、令牌或访问日志；启动日志只显示地址和密钥文件路径。配置密钥或数据库请勿作为附件提交。

## 统计解释与测试

安装研究编号不是独立人数；处理事件不是独立消息；命中规则不是确认移出。前台时长只表示本应用，启用/连接时长仅表示已观测片段，演示与试用分开看。这些记录不直接证明少查看手机、节省时间或减少漏看。

```powershell
.\.local\receiver-env\Scripts\python.exe -m unittest discover -s test/python/research_receiver -v
```
