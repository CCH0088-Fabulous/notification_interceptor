# 批量效果对比

从「预设管理」页顶工具菜单选择「批量效果对比」，或从某个预设卡片的「更多操作 → 对比应用效果」进入。
这是高级功能预览，与预设管理一起开放体验，当前未接入支付。

## 使用

1. 选择待比较的关键词或场景预设。
2. 选择今天、最近 7 天或全部记录，并设置最多比较最近 100、300 或 1000 条。
3. 点击「运行批量对比」，查看当前配置与应用该预设后，在同一批历史处理记录上的判定差异。

页面提供动作变化、新增预计移除、不再预计移除、仅命中规则变化四项计数，以及动作迁移矩阵、按应用统计和逐条明细。样本在应用数量上限之前排除常驻通知和系统分组汇总，分别显示排除数；JSON 的 `skippedOngoing` 为常驻排除数，旧报告缺少时按 0 读取。原始历史仍保留。
可筛选动作发生变化的记录，展开查看两侧命中规则、规则标识，以及原记录当时的处理和取消状态。

对比只读取快照，不应用预设、不改规则，也不重新发送或取消通知。
确认效果后，返回预设页按原有流程确认应用或切换场景。

## 如何理解结果

- 两侧均调用实际 Kotlin 规则引擎。候选配置与真正应用该预设使用同一套整组规则替换逻辑：关键词预设更新自身，场景预设替换其他场景；完整规则顺序、手动规则、全局开关和默认动作仍参与判断。
- 回放按每条历史记录当时的**处理时间**计算时段，使用设备**当前时区**。结果显示时区标识；不能还原设备过去使用的其他时区。
- 比较范围是本机保存的最近 1000 条历史窗口，系统汇总不参与比较。先按日期取范围，再排除汇总，最后取指定数量的最近记录。同一通知的多次更新作为不同处理事件保留，不代表不同通知数量。
- “预计移除”表示规则判定为拦截，不保证 Android 实际取消成功，也不评估横幅或声音是否已出现。原记录的历史取消状态仅作参考，不是新配置的实测结果。
- 正文被系统隐藏时只能使用可读取字段；页面显示数量。无效正则等静态问题会列出，两侧仍遵循原引擎跳过无效规则的行为。
- 全局过滤关闭时，两侧均遵守关闭状态，不会为了演示自动开启。
- 修改规则或预设后，旧结果标记过期，需要重新运行后才能导出；更改待比较条件时，页面也会提示当前展示的是上一次结果。

## 导出与独立图表

结果页点击「导出对比数据 JSON」，通过 Android 系统文件选择器保存，无需额外存储权限。取消不生成文件。
导出包含规则快照、通知可读取的标题与正文、逐条判定及统计，不包含原始 extras。文件只保存到选择的位置，不上传；分享前可自行检查内容。

独立图表文件位于 [batch-comparison.html](../visualizations/batch-comparison.html)，内嵌字体、图形与数据，可离线打开。
它展示动作流向、按应用前后对照、动作迁移矩阵和小时分布，并支持明细筛选与分页。
这是导出时的固定快照，不会跟随手机数据实时更新。使用新的 JSON 重新渲染即可更新图表，操作见[图表说明](../visualizations/README.md)。

导出协议为 `schemaVersion: 1`、`kind: notification_batch_comparison`。
其中 `before` / `after` 是两次规则回放预测，`historicalAction` / `cancelStatus` 是原始处理记录；两类含义分别保留。
