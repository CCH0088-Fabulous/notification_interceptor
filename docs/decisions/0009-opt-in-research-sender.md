# 0009：自愿研究统计与设备发送端

日期：2026-11-09

设备侧采集使用时长、分时处理量和关键操作，辅助产品研究及 BP 汇总；规则结构另行选择，不自动分享关键词、正则、包名、通知内容或自定义名称。核心通知过滤不依赖研究开关。

## 决策

- Flutter 研究 feature 负责设置、明确同意、预览/导出和同步状态；Kotlin 是同意、存储、计时与发送的唯一权威来源。
- 采集入口使用固定事件/指标白名单。通知观测与最终取消确认使用独立事件 ID 去重，重连存量和演示单列。采集失败不阻塞通知流水线。
- SQLite 保存在 noBackupFilesDir，与最多 1000 条的历史 JSONL 分离。事件保留 7 天、汇总和待发数据 30 天，并设置条数/大小上限；不声称无丢失。
- 单调时钟计时，按 UTC 小时及本地偏移切片。长时间未确认的间隔记录为缺口，不将开关开启推断为持续保护。
- 采用 API 26 基线自带的 JobScheduler，无新增运行时 SDK。持久周期任务遵守联网/不计费网络和电量约束；手动发送同样遵守网络设置。它不保证整点执行，被强行停止后也不承诺继续工作。
- HTTPS 完整接收地址与独立上传令牌由研究配置提供。令牌由 Keystore AES-GCM 加密，不回传 Dart、不进入日志、导出或网络错误信息。调试版只额外允许固定回环/模拟器主机 HTTP，正式版仅 HTTPS。
- 批次不可变、持久化，重试复用 batchId。接收端需要按 bucket/revision 更新，并在持久写入后返回匹配的 acceptedBatchId；单纯 HTTP 2xx 不作为成功。
- 更改目的地/授权范围会使旧队列失效；关闭研究停止任务和连接、删除本机研究数据。已上传数据由接收方按研究编号处理删除，本机不虚报已从服务器删除。

## 边界

本轮不实现公网接收端、全手机使用追踪或具体规则分享。不回读历史来追溯同意前的行为；同意后重连观察到的存量仅计入 existing 指标。清空通知历史不等于删除研究统计。客户端使用编号表示安装实例，不等同独立人数或完全匿名数据。演示样本不能作为真实用户效果；统计处理结果也不能直接证明节省时间或提高专注。
