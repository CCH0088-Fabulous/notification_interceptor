# 0011：免登录内测登记与十个安装名额

日期：2026-11-10

## 决策

手机无账号、密码或人工邀请码。内测 APK 预配置接收地址与仅用于登记的内测凭证；用户明确同意研究后，手机生成随机安装研究编号和 256 位独立上传凭证，先用 Keystore 加密持久化，再请求接收端登记。电脑仅保存凭证哈希，事务绑定编号后返回匹配确认。凭证自动生成/授权，不向用户展示或要求输入。登记凭证不能上传统计或访问管理页。

登记最多保留 10 个安装名额，用 SQLite 写事务防并发超额。相同编号与凭证重试幂等，不重复占位；关闭新登记不影响已有登记确认/上传；已撤销、已删除编号不得重新启用。撤销保留名额，管理员明确删除安装后释放名额并保留原编号哈希拒收标记。重装、清除数据、退出后重新加入产生新编号，不能据此识别同一自然人。

手机登记失败可重试；未获匹配登记确认的凭证不能发送统计。变更配置/退出时取消旧网络任务，禁止旧确认重新开启范围。研究、结构分享和自动上传仍分别同意。支持旧版手工配置以保留兼容性，但内测包将其折叠为高级设置。

接收端登记默认关闭，可在本机管理页开启/关闭、查看安装、修改备注、撤销与删除。登记门控只适用于分发给少量内测人员的安装包，不声称验证真实人或防止持有 APK 的人复制登记能力。异地试用仍需可达的 HTTPS 入口，不自动部署公网设施。

## 配置与迁移

SQLite v1 升级 v2 仅新增登记表与控制表，不修改已收统计。持久数据/登记凭证和本地构建配置均位于忽略的 `.local/`。构建工具将接收地址和登记凭证写入内测 BuildConfig；管理员密钥和任何设备上传凭证不进入 APK。未配置内测目的地的普通包仍可离线使用及手动配置。
