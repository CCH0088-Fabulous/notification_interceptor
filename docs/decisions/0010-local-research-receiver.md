# 0010：电脑本地研究接收端

日期：2026-11-09

## 决策

采用 Flask + Waitress，在独立的本机 Python 环境运行，默认仅监听 127.0.0.1。上传接口和管理页面分离鉴权：手机持有按安装实例绑定的受限上传令牌，管理页使用独立本机密钥和带 CSRF 防护的会话。

沿用发送端 v1 协议，严格拒绝未知字段、任意文本、非法数值和超限内容。只接受小时计数及已单独同意的脱敏规则结构；不保存原始请求体或访问日志。SQLite 使用事务、外键和 WAL；按研究编号+batchId 去重，按更高的小时/结构 revision 替换累计快照。同一标识同一修订内容冲突时整批回滚。数据库提交后才返回 acceptedBatchId。

上传令牌首次使用时绑定一个研究编号；撤销令牌停止后续上传。删除研究编号时删除其批次、小时和结构数据、撤销关联令牌，并保留哈希拒收标记，防止离线重试恢复已删除数据。较新的结构同意关闭状态会删除服务端现存结构；较旧批次不能重新打开范围。

管理页离线使用黑白和原版思源宋体，只允许从本机直接访问，不信任转发头。汇总和 CSV 按真实试用/演示分组选择，编号仅表示安装实例，不声称独立人数。无观测时段、漏采和异步取消确认均保留解释边界。

## 范围

本轮完成本地接收程序、持久数据库、令牌管理、研究编号详情/删除、小时汇总和 CSV 导出、可重复启动与退出。不会自动部署隧道、开放路由器端口或设置电脑开机任务，也不修改手机端每 4 小时的调度为白天窗口。后续外部接入应只转发上传路径，管理页保持本机访问。
