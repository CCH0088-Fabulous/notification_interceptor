# 0012：离线内测、一键分享与文件回收

日期：2026-11-10

## 决策

内测默认离线，仅在用户同意后本机记录，不自动登记或联网发送。每轮使用随机编号，结束记录保留编号和统计，删除数据另行确认。原在线协议保留给明确开启的兼容构建，普通内测包不包含在线凭证。

手机主操作“分享内测数据”在原生后台线程生成一个 ZIP，内容为固定名称 research.json，包含全部保留的小时快照、事件明细、当前已同意的脱敏规则结构、周期及裁剪诊断。文件不读取通知历史、具体过滤词或上传凭证。事件 ID 按本轮编号加盐散列，不能用导出文件直接关联本机通知历史 ID。系统分享只代表交给目标应用，不能声称研究者已收到。保留“保存到手机”作为兜底，分享/保存不确认网络队列、不删统计。

按用户明确要求：小时汇总 30 天、事件明细 14 天；事件上限增至 50000，小时组 4096，研究 SQLite 64 MiB。容量达到限制仍记录失败/裁剪诊断，不承诺没有缺口。临时分享文件独立限量清理。说明版本升级，旧同意版本停止新增记录但保留已有数据，不能静默扩展旧研究范围。

电脑仅本机管理员导入 ZIP，检查文件/解压大小、条目白名单和全部字段，不向磁盘解压。按导出编号幂等，小时高修订替换，事件 ID 去重，冲突整份回滚；统计图表只汇总小时，不再叠加事件。离线最多接纳 10 个编号，删除后释放并拒绝旧编号重新恢复。导入是人工回收的数据，不证明真实设备/身份或文件未被改动。文件及电脑已导入数据不自动受手机保留期清理，需按研究约定管理。

## 实现位置

`ResearchArchive` 及 `ResearchStore.writeArchive` 负责流式快照；`ResearchArchivePicker` 负责分享/保存，FileProvider 只授权固定缓存目录。Flutter research 页面精简为开始、分享、结束、删除及数据范围。电脑 `archive.py` 校验，storage v3 保存小时、明细、导入记录和离线编号，`/imports` 提供本机导入。
